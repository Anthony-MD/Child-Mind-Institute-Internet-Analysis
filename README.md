# Child Mind Institute: Problematic Internet Use Analysis & Prediction

## Descripción
Este es mi **Trabajo Final de Máster en Data Science**. El proyecto se centra en predecir y analizar el uso problemático de internet en niños y adolescentes, basándose en datos clínicos, físicos y de comportamiento. El objetivo es identificar patrones que permitan una intervención temprana en la salud mental de los jóvenes. Este reto fue seleccionado de una competencia real en kaggle.

## Stack Tecnológico
* **Modelos:** XGBoost, LightGBM, Random Forest (Ensemble Learning).
* **Procesamiento:** Scikit-learn, Pandas, NumPy.
* **Optimización:** Ajuste de hiperparámetros y manejo de desbalanceo de clases.
* **Visualización:** Seaborn, Matplotlib, análisis de importancia de variables (Feature Importance).

## Innovaciones y Metodología
* **Análisis Multivariable:** Integración de datos demográficos, actividad física y evaluaciones clínicas.
* **Precisión en Casos Críticos:** El modelo fue optimizado para identificar con alta fidelidad la **Clase 3 (Estatus Grave)**, logrando una discriminación efectiva esencial para diagnósticos clínicos reales.
* **Feature Engineering:** Creación y selección de variables clave que determinan la transición de un uso normal a uno problemático del internet.

## Conclusiones del Máster
* El modelo demuestra una capacidad sólida para separar clases complejas, permitiendo a los profesionales de la salud priorizar los casos de alto riesgo. 
* Se validó que los factores de actividad física y entorno social son predictores determinantes en la conducta digital.
